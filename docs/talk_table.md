# Talk Table Notes

The talk tables are generated by `scripts/make_population_table.py` into `data/processed/earth_artificial_bitops_population_table.md` and `.csv`.

- Rows 1945-2025 are historical-model p50 values. Rows marked `*` (2030, 2035) are p50 values of the component projection; p10/p90 are in `earth_artificial_bitops_projection_2026_2035.csv`.
- Both inclusive and non-PoW bitops and Landauer efficiencies are shown, because the inclusive values after 2015 mostly track proof-of-work.
- The contributor column is computed from the category shares; it is not free text.
- The energy table gives wall power, annual energy in TWh and erg, bitops per year, and bitops per erg.
