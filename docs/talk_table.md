# Talk Table Notes

The talk table uses inclusive artificial bitops/s.  SHA-256 proof-of-work is included because the table is an all-artificial-computation accounting exercise.

The 2025 row is labeled reconstructed/estimated, not future extrapolated.  The current date of the talk preparation is 2026, so 2025 is historical/current reconstruction.

The 2030 and 2035 rows are forward extrapolations of aggregate total bitops/s.  They should not be read as detailed forecasts of Bitcoin, AI, data-centre, mobile, network, or embedded contributions.  Qualitative contributor language such as "likely SHA-256 PoW plus AI/accelerator-scale compute" is interpretation, not a numerical stack allocation.
