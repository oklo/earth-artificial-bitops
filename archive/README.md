# Archive (deprecated)

`original_generated_files/` is the original flat bundle from version 0.1.0. It
is kept unchanged for provenance and is **not** a source of current results.

- Its scripts are not run by `make all` and its figures and tables are superseded by `data/processed/` and `figures/`.
- One file is still used as input: `earth_artificial_bitops_historical_categories.csv` supplies the non-proof-of-work category shares in `data/reference/` (see `scripts/build_reference_shares.py`), because the script that produced that breakdown was not preserved.

See `CHANGELOG.md` for what changed and why.
